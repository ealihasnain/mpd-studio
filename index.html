Settings

How persistence works

Layer 1 · localStorage — always-on. Every change saves to this browser instantly. Tied to this browser on this PC. Lost if browser data is cleared.

Layer 2 · Disk file (optional, recommended) — pick a state file once. From then on, every change auto-writes to disk after a 1-second idle. Drop the file in OneDrive and both your PCs share the same file naturally.

Layer 3 · Export / Import JSON — universal escape hatch. Works on any browser, with or without a connected file. Use to migrate state or hand off.

Cloud sync (private gist · works on mobile)
State lives in one secret gist that every device reads and writes. The token is stored on this device only — it never enters the state file or the gist. Pull runs on load and whenever this tab regains focus; push runs 3s after any edit. Conflicting edits raise a prompt rather than overwriting silently.
Disk file sync
Environment & override diagnostics
File handles are stored per browser origin and never sync. If a row shows picked at a different origin, re-pick that input here — the recorded filename is real, the handle just isn't reachable from this origin.
Auto-save to disk file
Off · localStorage only. The disk file (if any) won't update until you press Save now.
Workspace folder (for stage input auto-resolution)
Pick the parent folder containing your EP###_TopicShort/ subfolders. Once connected, "Copy payload" will automatically find and inline prior-stage artifacts (Strategy Brief, Voice Script, SRT, etc.) per the predicted naming convention. Per-input override pickers handle files that live elsewhere.
Manual migration
Export = download current state. Import = replace current state with an uploaded JSON. Useful for one-off transfer or backup snapshots.
JSON rating auto-fill
Default OFF — leave off when running mpd-audit as a manual gate before passing. When on, a 10/10 self-rating with no uncertainties skips the explicit "Mark passed" click.
Default ON. Turn off when capturing multiple revision cycles — each parse will append rather than overwrite the previous summary.
Active Rules display
Default ON. Stage card status line shows a count of how many active rules will be injected into that stage's payload.

Danger zone

Wipes localStorage on this browser. The connected disk file (if any) is unaffected and will repopulate localStorage on next file pull.
